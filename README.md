# EmpowerNext Vietnam Clean Energy Career Hub

A static, single-page web application for the EmpowerNext project. The site includes the six-month clean-energy career pathway, the 24-article library, interactive career tools, a glossary, article search, and an article reader.

## Publish with GitHub Pages

1. Extract this ZIP file on your computer.
2. Create or open the GitHub repository for the site.
3. Upload `index.html` and `README.md` to the repository's top level. Keep `index.html` at the root, not inside another folder.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. When deployment finishes, use the site link shown under **Settings → Pages**.

## Notes

- This is a static site; it does not need a server or database.
- Tailwind CSS and the fonts load from their CDNs, so those styles require an internet connection.
- Edit the content and interactions in `index.html`.
